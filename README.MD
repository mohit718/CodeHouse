# Project Description
An online coding interview platform supporting real-time video streaming, chat communication, and an 
integrated code runner with automated test case evaluation. Implemented secure authentication for both 
candidates and interviewers, ensuring a seamless one-on-one interview experience. The platform allows 
interviewers to assess coding performance instantly based on passed test cases.

## Frontend
> Vite + React
> React-Router
> Tanstack Query
> Tailwind v4
> DaisyUI v5
> Clerk React
> Piston
> Canvas Confetti
> React Resizable Panels
> Monaco Editor React

## Backend
